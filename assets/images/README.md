# Imagens do Projeto

## Foto do Especialista
- **Arquivo necessário**: `edilson-morais-palco.jpg`
- **Dimensões recomendadas**: 400x400px (mínimo)
- **Formato**: JPG ou PNG
- **Descrição**: Foto do Edilson Morais no palco, tocando

### Como adicionar a foto:
1. Salve a imagem da conversa como `edilson-morais-palco.jpg`
2. Coloque nesta pasta (`assets/images/`)
3. A página irá carregar automaticamente

### Fallback:
Se a imagem não for encontrada, será exibido o emoji 🎵 como placeholder.
